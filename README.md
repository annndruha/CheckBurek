# Android app for ping sites
# Приложение для проверки сайтов на доступность

Фишки:
* ICMP ping
* HTTP HEAD/GET (equal chain: dns + tcp + tls + http)
* Листы с сайтами

Особенно полезно для проверки состояния сети (белые списки, полное отсутствие интернета или некоректный dns)
